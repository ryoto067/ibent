# とるぞ！ミッションアプリ 公開手順

参加者がスマホでチーム番号を選ぶと、そのチームのお題が表示されます。お題ごとに写真をアップロードでき、同じチームのメンバー全員の画面に表示されます（15秒ごとに自動で更新）。写真はGoogleドライブに保存されます。

## 1. プロジェクトを作る（5分）

1. https://script.google.com を開いて「新しいプロジェクト」を押す
2. 左上の「無題のプロジェクト」を「とるぞ！ミッションアプリ」に変更
3. `コード.gs` の中身を全部消して、`Code.gs` の中身を貼り付ける
4. 左の「ファイル」の「＋」→「HTML」→ 名前を `index` にする（`.html` は自動でつきます）
5. `index.html` の中身を全部消して、このフォルダの `index.html` の中身を貼り付ける
6. 保存（⌘S）

## 2. 初回の権限の許可

1. 上の関数の選択で `setup` を選んで「実行」
2. 「承認が必要です」→ 自分のアカウントを選ぶ
3. 「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」
4. マイドライブに「とるぞ！フォトミッションラリー 写真」フォルダと、その中にチーム1〜4のフォルダができていればOK

## 3. Webアプリとして公開

1. 右上の「デプロイ」→「新しいデプロイ」
2. 歯車アイコン →「ウェブアプリ」
3. 設定
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」→ 表示された **ウェブアプリのURL** をコピー

## 4. チームごとのURL（QRコード用）

URLの最後に `?team=番号` をつけると、チーム選択を飛ばしてそのチームの画面が開きます。

- チーム1：`（ウェブアプリのURL）?team=1`
- チーム2：`（ウェブアプリのURL）?team=2`
- チーム3：`（ウェブアプリのURL）?team=3`
- チーム4：`（ウェブアプリのURL）?team=4`

当日はチーム発表のときに、各チームの全員に自分のチームのURL（またはQRコード）を送ると早いです。番号なしのURLを全体LINEで流して、各自でチームを選んでもらう形でも使えます。

## お題やチームを変えたいとき

`Code.gs` の上の方の設定ブロックだけ変えます。

- お題の文面：`MISSIONS`
- チームごとのお題とおすすめ順：`TEAM_MISSIONS`（今は全チーム同じ5題で、天守閣に4チームが同時に集まらないよう順番だけずらしています。最後は全チーム「映画のポスター風」で夕日の時間に合わせています）
- チーム数：`TEAM_COUNT`（増やしたら `TEAM_MISSIONS` にも追加）

変更したら「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」。これでURLは変わりません（「新しいデプロイ」を押すとURLが変わるので注意）。

## お題が表示されないとき

画面に赤い枠で「読み込めませんでした：…」と出ます。よくある原因は次のとおりです。

| 表示・状況 | 原因と対処 |
|---|---|
| `permission` / `権限` を含むメッセージ | 手順2の `setup` を実行していない。実行して許可する |
| Googleのログイン画面やエラーページになる | デプロイの「アクセスできるユーザー」が「全員」になっていない。「デプロイを管理」で直す |
| ブラウザで複数のGoogleアカウントにログインしている | Apps Scriptの既知の不具合で失敗することがある。シークレットウィンドウか、ログインしていないブラウザで開く |
| URLの末尾が `/dev` | テスト用URL。デプロイで表示された `/exec` で終わるURLを使う |
| コードを貼り替えたのに変わらない | 「デプロイを管理」→ 鉛筆 →「新バージョン」でデプロイし直す |

## 知っておくこと

- URLを知っている人は誰でも写真を見たり、アップロード・削除したりできます。URLは参加者と運営だけに共有してください。
- 削除した写真はドライブのゴミ箱に入り、30日間は復元できます。
- アップロードされた写真は自動で縮小（長辺1600px）されるので、通信量はそれほど多くありません。
- 画面の上に「このアプリケーションは Google Apps Script のユーザーによって作成されたものです」という帯が出ますが、Googleの仕様なので問題ありません。
- ベストショットは写真をタップして「ベストショットに選ぶ」で決められます。選ぶと画面の下に大きく表示されるので、長押しで保存して全体LINEに送れます。
- 本番の前に、下見のときに運営で実際に使ってテストしておくのがおすすめです。テスト用の写真はドライブのチームフォルダから削除してください。
